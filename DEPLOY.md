# Deploy ShopBot Mobile

Deploy only this project, not the sibling Workshop reference clone. Keep all records synthetic and use a dedicated database.

1. **Postgres:** Create a Supabase or Neon project. Save its direct or session-mode PostgreSQL connection string as `DATABASE_URL` (with SSL as required by the provider). Startup initializes the catalog and LangGraph checkpoint schema; the database role must have permission to create tables.
2. **API:** Publish this project to its own GitHub repository with `render.yaml` at the repository root. In Render, create a Blueprint connected to that repo. It provisions a Free Python web service, installs from `api/requirements.txt`, and starts Uvicorn on Render's assigned port. Enter `DATABASE_URL` and the group `ANTHROPIC_API_KEY` in Render's dashboard; Render generates `SELLER_TOKEN`. Set a conservative `MODEL_CALL_LIMIT` that leaves headroom for grading.
3. **Health:** Once Render reports the service live, run `python api/benchmark.py https://YOUR-SERVICE.onrender.com`. This sends no chat requests. A free service sleeps after 15 minutes of inactivity and can take about a minute to wake; retry the health check after wakeup and confirm the grader allows for cold starts. If startup fails, inspect Render logs without exposing credentials.
4. **Website:** Set `API_BASE` in `web/config.js` to the public HTTPS API URL without a trailing slash. Push the ShopBot project to its own public GitHub repo and import it into Vercel as a static site with Root Directory `web`. Set the final Vercel origin in the API host's `WEB_ORIGIN` and restart the API. Never put the seller token or provider credentials in the website source.
5. **Verify:** Open the storefront and seller dashboard. Verify catalog loading and seller authorization. Run the live benchmark against a fresh synthetic catalog, compare each result to the expected behavior, and retrieve billed usage from the group workspace. Don't count a successful HTTP response as a behavioral pass.
6. **Submit:** Record the 2–3 minute demo and capture the demo GIF and paper canvas photo. Add measured results and the GIF to the repo. Give the group leader the website, API, public repo, video, and photo links for the form and Classroom.
